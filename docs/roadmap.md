# Development Approach

Development is performed incrementally.

Each session should focus on a small number of concepts or systems.

Before moving to a more advanced system:

1. Understand the current system.
2. Implement it.
3. Test it.
4. Review the design.
5. Document what was learned.
6. Commit the working state.

The roadmap is a guide rather than a strict schedule.

Features may be moved, redesigned, or removed as development progresses.
