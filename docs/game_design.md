# Game Design

## Vision

InTerminal is a text-based RPG focused on exploration, discovery, and procedural generation.

Although the world changes between playthroughs, the main story remains consistent.

Every adventure should feel familiar but never identical.

---

# Core Gameplay Loop

Explore

↓

Fight

↓

Collect Loot

↓

Become Stronger

↓

Discover New Areas

↓

Continue Exploring

---

# Main Features

- Text-based gameplay
- Procedurally generated world
- Randomized dungeons
- Different items each playthrough
- Story-driven main quest
- Optional side quests
- Inventory system
- Character progression
- Save and load system

---

# Design Goals

- Easy to understand
- Easy to expand
- Replayable
- Modular
- Fun to experiment with
